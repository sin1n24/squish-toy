# 変顔クリエーター

好きな画像を選んで、指（マウス）でつまんで伸ばして変顔にできるブラウザトイ。

- 画像を選ぶと、まずトリミング画面が1回だけ表示される（そのまま使う場合は「全体を使う」）
- 画像をタップ長押し（マウスなら押下）→ドラッグでその部分が伸びる
- 離すと元の形に大きくオーバーシュートしながら戻る（バウンド強め）
- 「固定」をオンにしてから離すと、変形をキープしたまま重ね掛けできる（初期状態は固定オン）
- 「元に戻す」で直前の固定・リセットを1回分だけ取り消せる
- 「画像をシェア」でPNGを共有（対応環境では直接シェア、非対応環境は自動ダウンロード）
- 「動画をシェア」で、現状からリセット後へ行ってぷるんと弾んで戻る1往復のデモをwebm動画として共有・保存

単一構成（`index.html` / `style.css` / `script.js`）、外部サーバー・ライブラリ不要。
WebGL上でメッシュ変形を行っているため、スマホでも滑らかに動きます。
選んだ画像はサーバーに送信されず、共有ボタンを押すまで全てブラウザ内だけで処理されます。

## 動作確認

`index.html` をブラウザで直接開くか、GitHub Pages で公開するだけで動作します。

## シェアについて

Web Share API (`navigator.share`) に対応した環境（主にスマホ）では、画像・動画付きで直接
共有シートを開けます。非対応環境（主にPCブラウザ）では自動的にファイルをダウンロードします。
