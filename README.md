# 顔スクイッシュトイ (Squish Toy)

好きな画像をアップロードして、指（マウス）でつまんで伸ばして変顔にできるブラウザトイ。
スーパーマリオ64のタイトル画面「マリオの顔いじり」に着想を得た、画像非依存の汎用版です。

- 画像をタップ長押し（マウスなら押下）→ドラッグでその部分が伸びる
- 離すと元の形に戻る（ぷるんと弾む復元アニメーション）
- 「固定」をオンにしてから離すと、変形をキープしたまま重ね掛けできる
- PCなら `R` キーを押しながら離しても固定できる
- 変形結果はPNGでダウンロード、対応環境ではXへ画像付きで直接シェア可能

単一構成（`index.html` / `style.css` / `script.js`）、外部サーバー・ライブラリ不要。
WebGL上でメッシュ変形を行っているため、スマホでも滑らかに動きます。

## 動作確認

`index.html` をブラウザで直接開くか、GitHub Pages で公開するだけで動作します。

## Xシェアについて

X（旧Twitter）の Web Intent は画像添付に対応していないため、外部サーバーなしでは
「テキスト付きツイート画面を開く＋画像は自動ダウンロード」という形になります
（`navigator.share` に対応した環境ではスマホ標準の共有シートから画像付きで直接共有できます）。
